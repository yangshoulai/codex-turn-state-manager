全局总开关 关闭后探测、请求注入、响应捕获、账号调度干预四项能力全部旁路
定时探测 在全局总开关开启时生效，受时间窗口限制
反向绑定 从正常业务流量响应头中捕获 State 并绑定
账号调度干预 干预的总开关：关闭后插件完全不碰 CPA 的账号选择。开启时按下方「干预方式」执行；两种状态下 State 注入都不受影响
干预方式 前者不越过 CPA 的优先级档，档内没有持 State 的账号时就不干预；后者会在持有 State 的账号里取最高档，因此可能选到优先级较低但持有 State 的账号

代理池

探测按「最久未使用优先」遍历，直到命中目标长度或达成单轮上限。HTTP / HTTPS / SOCKS5 均可。地址与开关改动即时保存。
